# AFTERPACT — Competitive Moat (honest assessment)

## What is NOT a moat

AI models, generic rule engines, and open-source code alone create no durable
advantage. The current build is MIT-licensed; anyone can fork the mechanics.
No moat is claimed today.

## Candidate moat sources (to be earned)

1. **Exception-resolution workflows that survive contact with ops teams.**
   Policy packs per vertical (delivery promises, service completion,
   B2B milestones) refined across pilots — tacit, data-driven, hard to copy.
2. **Evaluation datasets.** Adversarial + concurrency + reconciliation cases
   (`tests/`, Postman negatives) grown into a regression corpus that gates
   every release. Whoever has the best corpus ships the safest changes.
3. **Integration depth.** PayPal reconciliation edge cases, Channel3
   normalization quirks, merchant evidence formats — unglamorous coverage
   that compounds.
4. **Auditability reputation.** Hash-chained Flight Recorder exports that
   auditors and enterprise buyers learn to trust; switching costs rise once
   the export format is embedded in merchant SOPs.
5. **Incident-resolution accuracy.** Measured precision/recall on discrepancy
   detection and refund sizing — publishable benchmarks competitors must beat.

## What would need to be true in 12 months

- 3+ vertical policy packs with measured false-positive/negative rates.
- Public eval corpus with third-party reproductions.
- Two reference merchants willing to be named (none today — no claim).
- SOC 2 Type I started (not started; enterprise deals stall without it).
